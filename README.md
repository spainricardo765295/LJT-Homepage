# LJT-Homepage

Personal academic homepage of **Junteng Liu**, first-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology.

This repository is a fork of the [Academic Pages template](https://github.com/academicpages/academicpages.github.io), a Jekyll theme for academic personal websites hosted on GitHub Pages.

## Site contents

- **About (home page)** — `_pages/about.md`: personal details, research interests and skills, education, research experience, publications, honors and awards, and contact information.
- **Publications** — `_pages/publications.html` lists the papers stored in `_publications/`.

## Configuration

- Site-wide settings and author profile: `_config.yml`
- Header navigation: `_data/navigation.yml`

See the [Academic Pages documentation](https://github.com/academicpages/academicpages.github.io) for details on the underlying template.
